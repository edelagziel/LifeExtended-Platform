# LifeExtended

LifeExtended is a wellness-oriented application with user, administration, serverless backend, and research-server components.

## Repository structure

- `apps/client/` — User Application
- `apps/admin/` — Admin Application
- `backend/functions/` — Serverless Backend
- `server/` — Research Server
- `infrastructure/` — AWS architecture documentation to be added later
- `docs/` — Project documentation

AWS architecture documentation will be added later.
